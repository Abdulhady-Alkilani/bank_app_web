# دليل التحقيق / Investigation Guide

ابدأ دائماً بـ `get_alert_details` ثم `explain_score`، ثم ادخل في مسار الحالة المناسب.
Always start with `get_alert_details` then `explain_score`, then follow the matching playbook.

## A. الاستيلاء على الحساب / Account takeover

مؤشرات / Signals: جهاز جديد، تغيير رقم الهاتف أو SIM قبل التحويل بوقت قصير، رفع الحد، إضافة مستفيد جديد ثم تحويل كبير، موقع/IP غير معتاد.

1. `get_account_profile` - قارن المبلغ والساعة والمدينة بسلوك العميل المعتاد.
2. `get_transaction_history` (days=30) - هل التحويل أكبر بكثير من المتوسط؟ هل هناك محاولات دخول متتالية؟
3. `get_device_links` - هل الجهاز جديد وغير موثوق؟ هل هو مشترك مع حسابات أخرى؟
4. تحقق من التسلسل الزمني في `get_alert_details`: (تغيير هاتف -> إضافة مستفيد -> تحويل) خلال ساعة يعني خطورة عالية.
5. التوصية المعتادة / Typical recommendation: `propose_action` بـ `freeze_account` أو `require_otp`، مع التواصل مع العميل عبر قناة موثوقة.

## B. حسابات البغل / Mule accounts

مؤشرات / Signals: حساب مستفيد يستقبل من حسابات كثيرة خلال وقت قصير (fan-out/fan-in)، عمر حساب قصير، سحب سريع بعد الإيداع، مبالغ مقسّمة.

1. `find_related_accounts` (depth=2 ثم 3) - اكتشف العنقود وعدد الحسابات المرتبطة.
2. `get_transaction_history` للحساب المشبوه - أنماط الإيداع/السحب السريع.
3. `get_device_links` - أجهزة مشتركة بين حسابات "غير مترابطة" ظاهرياً.
4. التوصية / Recommendation: `freeze_beneficiary` للمستفيد المشتبه، ثم `add_case_note` يوثق الشبكة (أرقام مقنّعة).

## C. الجهاز المشترك / Shared device

مؤشرات / Signals: جهاز واحد تستخدمه عدة هويات، أو عدة حسابات تدخل من نفس الجهاز/IP خلال ساعة.

1. `get_device_links` - عدد الحسابات التي تشارك الجهاز.
2. `find_related_accounts` - هل الحسابات المشتركة لها درجات خطورة عالية سابقة؟
3. فرّق بين الاستخدام العائلي المشروع (حسابات بنفس المعلومات والسلوك المنتظم) والاحتيال المنظم (حسابات حديثة، مستفيدون مشتركون).
4. التوصية / Recommendation: `require_otp` أو مراقبة معززة، وللحالات المؤكدة `freeze_account`.

## قواعد عامة / General rules

- لا تعتمد على درجة واحدة؛ اجمع عدة أدلة مستقلة.
- اذكر مستوى الثقة والنقاط غير المؤكدة.
- القرار النهائي للمحلل البشري؛ استخدم أدوات الاقتراح فقط.
- لا تكشف أو تحاول استنتاج بيانات مقنّعة.
